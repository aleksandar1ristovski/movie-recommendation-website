# Movie Recommendation Web Page

A Letterboxd-style web app that recommends movies to users, lets them
save films as **Watched** or **Watchlist**, and generates statistics
based on what they've watched.

## Features
- Movie recommendations on a dedicated suggestions page
- Mark movies as Watched or add them to a Watchlist
- Personal profile page with stats about your watched movies
- Movie details view
- Separate pages for home, suggestions and profile

## Technologies
- HTML
- CSS
- JavaScript

## How to run
1. Download or clone this repository.
2. Open `index.html` in your browser. (Use the name of your main page.)

No installation or server is needed.
